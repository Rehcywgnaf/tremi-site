# Site TRéMI

Première version de la landing page de TRéMI, préparée pour GitHub Pages.

**Brouillon privé — aucune publication autorisée à ce stade.** Aucun workflow de déploiement n’est installé. GitHub Pages doit rester désactivé jusqu’à validation explicite.

Site statique, sans compilation, dépendance JavaScript, formulaire ni outil de mesure d’audience. Police et logos servis localement. Ouvrir `index.html` ou lancer `python3 -m http.server 4173` dans ce dossier pour l’aperçu.
