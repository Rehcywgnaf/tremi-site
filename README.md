# TRéMI — site web

Site de présentation de TRéMI : photographie, vidéo et création collective à Roubaix et dans la métropole lilloise.

Contenu, identité visuelle et défilement validés le 27 septembre 2026.

## Fonctionnement

Site statique compatible avec GitHub Pages, sans compilation ni dépendance JavaScript. Les polices et les logos sont servis localement. Aucun formulaire ni outil de mesure d’audience n’est intégré.

Pour un aperçu local : ouvrir `index.html`, ou lancer `python3 -m http.server 4173` dans ce dossier.

Publication GitHub Pages : branche `main`, dossier racine. Les modifications de cette branche seront mises en ligne automatiquement une fois Pages activé.
